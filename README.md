# Повторение - Вариант 1

## Задание 1:
В соответствии с вариантом задания организовать ввод требуемых исходных данных и вывод результатов расчета с использованием компонентов класса TextBox. При наличии в формуле числа pi, подставлять значение Math.PI.

Из куба с ребром a был выточен шар радиуса R (R <= a/2). Вычислить объемы куба и шара (V(шар) = (4/3)pi*R^3), а также процент материала, ушедшего в отходы.

## Задание 2:
Составить программу, которая будет:
а) генерировать данные, сохраняя их в формате csv, xml или json (подобрать оптимальный формат хранения данных)
б) считывать данные из файла и выполнять операции в соответствии с заданием.

Таблица содержит данные об итогах защиты дипломных работ и включает фамилию, имя студента, группу и оценку. Вывести данные о студентах, учащихся в заданной группе и получивших заданную оценку.
